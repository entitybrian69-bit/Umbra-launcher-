## Verified results (command output, not claims)

All from `tools/run_tests.sh` on this machine (Linux x86_64, gcc 12.2.0,
Goose v2026.4 at commit `6c1fbc78`):

```
PASS mem (19 checks)
inflate: 72 streams matched zlib byte for byte, 4 corrupt streams rejected
PASS inflate (97 checks)
zip: 4 archives, 20 entries matched their originals
zip: 2 corrupt archives rejected
PASS zip (137 checks)
png: 10 images decoded to their expected RGBA, 4 broken refused
PASS png (153 checks)
nbt: parsed and rewrote level.dat byte for byte, 4 broken files refused
PASS nbt (196 checks)
PASS region (237 checks)
```

What those numbers mean:

* **inflate**: our RFC 1951/1950 decoder reproduces Python's `zlib` output
  exactly on 72 streams (every level/strategy combination generated), and
  refuses 4 deliberately corrupt streams. The oracle is zlib, not our own
  compressor.
* **zip**: 20 entries across 4 archives written by Python's `zipfile` extract
  byte-identically; a flipped CRC and a flipped payload byte are both refused.
* **png**: 10 images (all five filters, colour types 0/2/3/4/6, 8- and 4-bit
  palettes) decode to the RGBA an independent encoder wrote; 4 broken images
  are refused.
* **nbt**: a level.dat-shaped document with every tag type is parsed, 40 named
  paths are checked, and rewriting the parsed document reproduces the input
  byte for byte. 4 broken documents are refused.
* **region**: an Anvil region written by an independent Python writer opens;
  3 chunk columns decode; terrain, properties, palettes, bit packing, the
  compressed-store writer and a read-back of a written chunk all check out;
  3 broken regions are refused.

## Not verified, and must not be claimed

* Nothing runs on a phone yet. No GPU code has executed anywhere.
* No world generated by the real server has been opened. No parity numbers
  exist. Umbra is not Minecraft and the parity table is empty.
* The `zlib_store` writer is valid zlib but not compressed; chunk files written
  by Umbra are larger than the game's. The real server has not yet been asked
  to open one.
